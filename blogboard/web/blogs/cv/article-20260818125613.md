## What is a CNN?

A **Convolutional Neural Network (CNN)** is a class of deep neural networks specifically designed to process data with a grid‑like topology, most commonly images. By leveraging **local connectivity**, **weight sharing**, and **spatial invariance**, CNNs can automatically learn hierarchical feature representations—from edges in early layers to object parts and whole objects in deeper layers.

---

## Core Building Blocks

### Convolution Layer
The convolution layer applies a set of learnable kernels (filters) across the input volume to produce feature maps.

```python
import torch.nn as nn

conv = nn.Conv2d(
    in_channels=3,      # RGB image
    out_channels=64,    # number of filters
    kernel_size=3,      # 3×3 kernel
    stride=1,
    padding=1,          # preserve spatial size
    bias=False
)
```

**Key concepts**
- **Kernel size (k×k)** determines receptive field.
- **Stride** controls down‑sampling.
- **Padding** preserves borders (same convolution) or reduces size (valid convolution).
- **Depthwise separable** and **grouped** convolutions reduce computation.

### Pooling Layer
Pooling aggregates spatial information, providing translation invariance and reducing dimensionality.

| Type | Typical Kernel | Effect |
|------|----------------|--------|
| **MaxPool** | 2×2, stride 2 | Keeps the strongest activation |
| **AvgPool** | 2×2, stride 2 | Computes average, useful for global pooling |

```python
pool = nn.MaxPool2d(kernel_size=2, stride=2)
```

### Activation Functions
Non‑linearities enable networks to approximate complex functions.

| Activation | Formula | Typical Use |
|------------|---------|-------------|
| **ReLU**   | `max(0, x)` | Default for most CNNs |
| **LeakyReLU** | `max(αx, x)` (α≈0.01) | Mitigates dying ReLU |
| **ELU** | `x if x>0 else α*(exp(x)-1)` | Faster convergence |
| **Swish** | `x·sigmoid(βx)` | Recent state‑of‑the‑art |

```python
act = nn.ReLU(inplace=True)
```

### Fully‑Connected (Dense) Layer
After a series of convolutional/pooling blocks, the feature map is flattened and fed into one or more dense layers for classification or regression.

```python
fc = nn.Linear(in_features=512, out_features=10)  # 10‑class classifier
```

### Batch Normalization
BatchNorm normalizes activations across the mini‑batch, stabilizing training and allowing higher learning rates.

```python
bn = nn.BatchNorm2d(num_features=64)
```

*Mathematical note*: For each channel *c*,
\[
\hat{x}_{i,c} = \frac{x_{i,c} - \mu_c}{\sqrt{\sigma_c^2 + \epsilon}},\quad
y_{i,c} = \gamma_c \hat{x}_{i,c} + \beta_c
\]
where \(\mu_c, \sigma_c^2\) are batch statistics, and \(\gamma_c, \beta_c\) are learnable scale/shift parameters.

### Dropout
Randomly zeroes a fraction *p* of activations during training, reducing over‑fitting.

```python
drop = nn.Dropout(p=0.5)
```

## Mathematical Foundations

### Discrete Convolution
For a 2‑D input \(I\) and a kernel \(K\) of size \(k \times k\),

\[
S(i,j) = (I * K)(i,j) = \sum_{u=0}^{k-1}\sum_{v=0}^{k-1} I(i+u, j+v) \cdot K(u,v)
\]

In deep learning frameworks the operation is **cross‑correlation** (kernel is not flipped), but the term *convolution* persists.

### Back‑Propagation Through Convolution
During training we need gradients w.r.t. both **weights** and **inputs**.

- **Weight gradient**:
  \[
  \frac{\partial L}{\partial K} = I \star \frac{\partial L}{\partial S}
  \]
  where \(\star\) denotes convolution with the input padded appropriately.

- **Input gradient**:
  \[
  \frac{\partial L}{\partial I} = K_{\text{rot}} * \frac{\partial L}{\partial S}
  \]
  where \(K_{\text{rot}}\) is the kernel rotated 180°.

Automatic differentiation (autograd) handles these steps, but understanding them helps debug shape mismatches.

### Gradient Descent & Optimizers
Standard update rule:
\[
\theta_{t+1} = \theta_t - \eta \cdot \nabla_\theta \mathcal{L}(\theta_t)
\]
where \(\eta\) is the learning rate. Modern optimizers augment this with momentum, adaptive scaling, or variance reduction:

- **SGD + Momentum**: \(v_{t+1}= \mu v_t + \eta \nabla\), \(\theta_{t+1}= \theta_t - v_{t+1}\)
- **Adam**: maintains per‑parameter estimates of first (\(m_t\)) and second (\(v_t\)) moments.

## Classic CNN Architectures

### 4.1 LeNet‑5 (1998)
- **Motivation**: Handwritten digit recognition (MNIST).  
- **Structure**: 2 conv layers → subsampling (average pooling) → 2 fully‑connected layers → softmax.  
- **Key innovation**: Early use of learned kernels and weight sharing.

### 4.2 AlexNet (2012)
- **Breakthrough**: Won ImageNet 2012, popularized ReLU, dropout, and GPU training.  
- **Design**: 5 conv layers (some with large 11×11 kernels), 3 FC layers, **LRN** (local response normalization) (now rarely used).

### 4.3 VGG Family (2014)
- **Principle**: Use only 3×3 conv kernels stacked repeatedly; depth = 16 or 19 layers.  
- **Pros**: Simplicity, uniform architecture.  
- **Cons**: High parameter count → heavy memory.

### 4.4 ResNet (2015)
- **Core idea**: **Residual blocks** with identity shortcuts.
\[
\mathbf{y}= \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}
\]
- Enables training of **hundreds** of layers (ResNet‑152).  
- Variants: **Bottleneck** (1×1 → 3×3 → 1×1) and **Pre‑activation** (BatchNorm‑ReLU before conv).

### 4.5 Inception (GoogLeNet, 2014)
- **Inception module** concatenates parallel filters of sizes 1×1, 3×3, 5×5 plus pooling.  
- Uses **1×1 convolutions** for dimensionality reduction → computational efficiency.

### 4.6 EfficientNet (2019)
- **Compound scaling** balances depth, width, and resolution with a single coefficient \(\phi\).  
- Achieves state‑of‑the‑art accuracy with **~5× fewer FLOPs** than comparable models.

## Training Tricks & Best Practices

### 5.1 Weight Initialization
- **He (Kaiming) initialization** for ReLU:
  \[
  W \sim \mathcal{N}\big(0, \frac{2}{\text{fan\_in}}\big)
  \]
- **Xavier (Glorot)** for tanh/sigmoid.

```python
nn.init.kaiming_normal_(conv.weight, mode='fan_out', nonlinearity='relu')
```

### 5.2 Learning‑Rate Schedules & Warm‑up
- **Step decay**, **Cosine annealing**, **Cyclic LR**.  
- **Warm‑up** (gradually increase LR for first few epochs) stabilizes large‑batch training.

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=200)
```

### 5.3 Data Augmentation & Normalization
| Technique | Effect |
|-----------|--------|
| RandomCrop, RandomResizedCrop | Improves scale invariance |
| HorizontalFlip | Mirrors images |
| ColorJitter | Simulates lighting changes |
| CutMix / MixUp | Regularizes by mixing images & labels |

```python
transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(brightness=0.2, contrast=0.2),
    transforms.ToTensor(),
    transforms.Normalize(mean=[0.485, 0.456, 0.406],
                         std =[0.229, 0.224, 0.225])
])
```

### 5.4 Regularization
- **L2 weight decay** (often set to 1e‑4).  
- **Dropout** (commonly 0.5 in FC layers).  
- **Stochastic Depth** (randomly skip residual blocks).

### 5.5 Optimizer Choices
| Optimizer | When to use |
|-----------|-------------|
| **SGD + Momentum** | Large‑scale image classification, when you need reproducibility |
| **AdamW** | Faster convergence on smaller datasets, transformer‑style training |
| **RMSprop
