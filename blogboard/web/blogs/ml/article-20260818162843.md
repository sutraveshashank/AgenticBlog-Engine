## Introduction

Drug discovery hinges on the ability to **predict molecular properties**—solubility, toxicity, binding affinity, metabolic stability, etc.—early in the pipeline. Traditional quantitative structure‑activity relationship (QSAR) models rely on handcrafted descriptors (e.g., Morgan fingerprints) and linear or tree‑based regressors. While successful in narrow domains, these approaches struggle to capture **higher‑order chemical interactions** and **non‑local electronic effects** that are crucial for modern therapeutic targets.

**Graph Neural Networks (GNNs)** have emerged as a powerful alternative because they operate directly on the **graph representation of molecules**, where atoms are nodes and bonds are edges. By iteratively aggregating information from a node’s neighborhood, GNNs learn **task‑specific, data‑driven embeddings** that respect the underlying chemistry.

This tutorial provides a **deep dive** into how GNNs are applied to molecular property prediction in drug discovery, covering:

* The nuances of molecular graph construction.  
* Architecture families tailored for chemistry, with pros/cons.  
* Strategies for fusing **quantum‑chemical** information.  
* Techniques for **scalable training** on libraries of millions of compounds.  
* Methods to **interpret** GNN predictions for medicinal chemistry insight.

By the end, you should be equipped to design, train, and rationalize GNN‑based models for real‑world drug discovery projects.

## Molecular Graph Representation

### 1. Basic Graph Formalism

A molecule is modeled as an undirected graph \( G = (V, E) \):

| Symbol | Meaning |
|--------|---------|
| \( V \) | Set of atoms (nodes) |
| \( E \) | Set of chemical bonds (edges) |
| \( \mathbf{x}_i \) | Feature vector for atom \( i \) |
| \( \mathbf{e}_{ij} \) | Feature vector for bond \( (i, j) \) |

Typical atom features include:

* **Atomic number** (one‑hot or integer).  
* **Hybridization** (sp, sp², sp³).  
* **Formal charge**, **aromaticity**, **ring membership**, **partial charge** (e.g., Gasteiger).  

Bond features often encode:

* **Bond type** (single, double, triple, aromatic).  
* **Conjugation**, **ring status**, **stereochemistry** (cis/trans).  

### 2. From SMILES to Graphs

```python
# PyTorch Geometric example: SMILES → Data object
from rdkit import Chem
from torch_geometric.data import Data
import torch

def mol_to_graph(smiles):
    mol = Chem.MolFromSmiles(smiles)
    Chem.Kekulize(mol)
    # Atom features
    atom_features = []
    for atom in mol.GetAtoms():
        atomic_num = atom.GetAtomicNum()
        aromatic = 1 if atom.GetIsAromatic() else 0
        hybrid = atom.GetHybridization()
        atom_features.append([atomic_num, aromatic, hybrid])
    x = torch.tensor(atom_features, dtype=torch.float)

    # Edge index & edge features
    edge_index = []
    edge_attr = []
    for bond in mol.GetBonds():
        i = bond.GetBeginAtomIdx()
        j = bond.GetEndAtomIdx()
        bond_type = bond.GetBondTypeAsDouble()
        edge_index += [[i, j], [j, i]]          # undirected
        edge_attr += [[bond_type], [bond_type]]
    edge_index = torch.tensor(edge_index, dtype=torch.long).t().contiguous()
    edge_attr = torch.tensor(edge_attr, dtype=torch.float)

    return Data(x=x, edge_index=edge_index, edge_attr=edge_attr)

graph = mol_to_graph('CC(=O)Oc1ccccc1C(=O)O')
print(graph)
```

### 3. 3‑D Geometric Information

For **quantum‑chemical** or **physics‑inspired** GNNs (e.g., SchNet, DimeNet), we augment the graph with **atomic coordinates** \( \mathbf{r}_i \). These coordinates can be:

* **Experimental crystal structures** (rare for drug‑like molecules).  
* **Conformers generated by RDKit, Open Babel, or MMFF**.  
* **Optimized geometries from semi‑empirical/DFT calculations** (see Section 4).

## GNN Architecture Variations for Chemistry

Different GNN families trade off **expressivity**, **computational cost**, and **chemical inductive bias**. Below we dissect the most widely used architectures, summarizing their core update rule, strengths, and limitations for molecular tasks.

### 3.1 Message Passing Neural Networks (MPNN)

**Core idea** (Gilmer et al., 2017) – each iteration consists of a **message** phase and an **update** phase:

\[
\mathbf{m}_{i}^{(t)} = \sum_{j \in \mathcal{N}(i)} \phi\big(\mathbf{x}_i^{(t)}, \mathbf{x}_j^{(t)}, \mathbf{e}_{ij}\big)
\]
\[
\mathbf{x}_i^{(t+1)} = \psi\big(\mathbf{x}_i^{(t)}, \mathbf{m}_{i}^{(t)}\big)
\]

* **Pros**: Highly flexible; can embed any differentiable message function.  
* **Cons**: Standard MPNNs are **invariant to 3‑D geometry** unless explicit distance features are added.

#### Example: D-MPNN (Directed MPNN)

```python
class DMPNN(torch.nn.Module):
    def __init__(self, hidden_dim, n_layers):
        super().__init__()
        self.message_nn = torch.nn.Linear(hidden_dim*2 + 1, hidden_dim)
        self.update_nn  = torch.nn.GRUCell(hidden_dim, hidden_dim)
        self.n_layers = n_layers

    def forward(self, x, edge_index, edge_attr):
        h = x
        for _ in range(self.n_layers):
            src, dst = edge_index
            m = torch.cat([h[src], h[dst], edge_attr], dim=-1)
            m = torch.relu(self.message_nn(m))
            agg = torch_scatter.scatter_add(m, dst, dim=0, dim_size=h.size(0))
            h = self.update_nn(agg, h)
        return h
```

*Used extensively in the **MoleculeNet** benchmark for regression tasks such as solubility and log P.*

### 3.2 Graph Convolutional Networks (GCN)

**Kipf & Welling (2017)** introduced a **spectral‑based** convolution:

\[
\mathbf{X}^{(t+1)} = \sigma\!\big( \tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2}\mathbf{X}^{(t)}\mathbf{W}^{(t)} \big)
\]

where \( \tilde{A}=A+I \) and \( \tilde{D} \) is its degree matrix.

* **Pros**: Simple, fast, and works well with **large, sparse datasets**.  
* **Cons**: The **linear aggregation** can under‑represent complex bond types; often requires **edge‑type encoding** (e.g., edge‑wise gating) to be chemistry‑aware.

#### Chemistry‑aware GCN (Edge‑Gated GCN)

```python
class EdgeGatedGCN(torch.nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.lin_node = torch.nn.Linear(hidden_dim, hidden_dim)
        self.lin_edge = torch.nn.Linear(1, hidden_dim)  # bond type scalar
        self.gate = torch.nn.Sigmoid()

    def forward(self, x, edge_index, edge_attr):
        src, dst = edge_index
        edge_msg = self.lin_edge(edge_attr)
        node_msg = self.lin_node(x[src])
        gate = self.gate(edge_msg + node_msg)
        agg = torch_scatter.scatter_add(gate * node_msg, dst, dim=0, dim_size=x.size(0))
        return torch.relu(agg + x)   # residual connection
```

### 3.3 Graph Attention Networks (GAT)

**Velickovic et al. (2018)** introduced **self‑attention** on graphs:

\[
\alpha_{ij} = \frac{\exp\big(\text{LeakyReLU}(\mathbf{a}^{\top}[ \mathbf{W}\mathbf{x}_i \, || \, \mathbf{W}\mathbf{x}_j])\big)}{\sum_{k\in\mathcal{N}(i)} \exp(\dots)}
\]
\[
\mathbf{x}_i^{(t+1)} = \sigma\!\big(\sum_{j\in\mathcal{N}(i)} \alpha_{ij}\mathbf{W}\mathbf{x}_j\big)
\]

* **Pros**: Learns **adaptive weighting** of neighboring atoms, useful for hetero‑atom rich scaffolds.  
* **Cons**: **Quadratic complexity** in the number of edges per layer; can be memory‑intensive for large libraries.

#### Multi‑Head GAT for Molecules

```python
from torch_geometric.nn import GATConv

class MoleculeGAT(torch.nn.Module):
    def __init__(self, hidden_dim, heads=8):
        super().__init__()
        self.gat1 = GATConv(in_channels=hidden_dim,
                           out_channels=hidden_dim//heads,
                           heads=heads,
                           edge_dim=1)   # bond type
        self.gat2 = GATConv(hidden_dim, hidden_dim, heads=1, edge_dim=1)

    def forward(self, x, edge_index, edge_attr):
        x = torch.relu(self.gat1(x, edge_index, edge_attr))
        x = torch.relu(self.gat2(x, edge_index, edge_attr))
        return x
```

### 3.4 Geometric Deep Learning Models for Molecules

These models explicitly incorporate **inter‑atomic distances** and **angular information**, making them well‑suited for **quantum‑chemical property prediction**.

| Model | Key Innovation | Typical Use‑Case |
|-------|----------------|-----------------|
| **SchNet** (Schütt et al., 2018) | Continuous‑filter convolution on distances; rotationally invariant. | Formation energy, dipole moments. |
| **DimeNet** (Klicpera et al., 2020) | Directional message passing using **bond angles**; high expressivity for **spectral properties**. | HOMO‑LUMO gaps, vibrational frequencies. |
| **PhysNet** (Unke & Meuwly, 2019) | Combines SchNet with physically motivated energy terms (electrostatics, dispersion). | Accurate potential energy surfaces. |

#### SchNet‑style Block (PyTorch Geometric)

```python
from torch_geometric.nn import SchNetInteraction, SchNetEmbedding

class SchNetMolecule(torch.nn.Module):
    def __init__(self, hidden_dim=128, num_interactions=3):
        super().__init__()
        self.emb = SchNetEmbedding(num_embeddings=100, hidden_channels=hidden_dim)
        self.interactions = torch.nn.ModuleList([
            SchNetInteraction(hidden_channels=hidden_dim) for _ in range(num_interactions)
        ])
        self.readout = torch.nn.Linear(hidden_dim, 1)   # e.g., regression

    def forward(self, z, pos, batch):
        h = self.emb(z)
        for layer in self.interactions:
            h = layer(h, pos, batch)
        # Global pooling (mean over atoms)
        h = torch_scatter.scatter_mean(h, batch, dim=0)
        return self.readout(h).squeeze()
```

*Note*: `z` is the atomic number tensor, `pos` the 3‑D coordinates, and `batch` groups
