## Why Evaluation Metrics Matter <a name="why-evaluation-metrics-matter"></a>

Choosing the right metric is **as important as selecting the model itself**. A metric translates raw predictions into a business‑relevant signal—whether you care about catching fraud (high recall), minimizing false alarms (high precision), or ranking search results (high NDCG). Using an inappropriate metric can lead to:

* Over‑optimistic model selection  
* Misaligned business objectives  
* Hidden biases (e.g., class imbalance)  

The sections below walk through the most widely used metrics, explain their mathematics, provide intuition, and show how to compute them with **scikit‑learn**.

## Classification Metrics <a name="classification-metrics"></a>

### Accuracy <a name="accuracy"></a>

**Definition**  
\[
\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}
\]

**Intuition**  
Proportion of correctly classified instances. Works well when classes are *balanced*.

**When to Use / Avoid**  
*Use* for balanced datasets or when misclassification costs are symmetric.  
*Avoid* on highly imbalanced data (e.g., 99% negatives) because a trivial classifier can achieve >99% accuracy.

**Scikit‑learn Example**

```python
from sklearn.metrics import accuracy_score, confusion_matrix
y_true = [0, 1, 1, 0, 1]
y_pred = [0, 0, 1, 0, 1]

acc = accuracy_score(y_true, y_pred)
cm = confusion_matrix(y_true, y_pred)

print(f"Accuracy: {acc:.3f}")
print("Confusion Matrix:\n", cm)
```

**Visualization** – Heatmap of the confusion matrix (see Section 6).

### Precision, Recall & F1‑Score <a name="precision-recall--f1-score"></a>

| Metric      | Formula (binary)                                 | What it measures |
|-------------|--------------------------------------------------|------------------|
| **Precision** | \(\displaystyle \frac{TP}{TP+FP}\)                | Correctness of positive predictions |
| **Recall**    | \(\displaystyle \frac{TP}{TP+FN}\)                | Ability to find all positive instances |
| **F1‑Score**  | \(\displaystyle 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}\) | Harmonic mean – balances precision & recall |

**Intuition**  
- **Precision** → “When I say it’s spam, how often am I right?”  
- **Recall** → “How many of the actual spam messages did I catch?”  
- **F1** → Single number that penalizes extreme imbalance between the two.

**When to Use / Avoid**  
- **Precision‑oriented** tasks: medical diagnosis (false positives costly).  
- **Recall‑oriented** tasks: fraud detection (missing a fraud is costly).  
- Use **F1** when you need a single metric and both errors matter.

**Scikit‑learn Example**

```python
from sklearn.metrics import precision_score, recall_score, f1_score

precision = precision_score(y_true, y_pred, pos_label=1)
recall    = recall_score(y_true, y_pred, pos_label=1)
f1        = f1_score(y_true, y_pred, pos_label=1)

print(f"Precision: {precision:.3f}")
print(f"Recall:    {recall:.3f}")
print(f"F1‑Score:  {f1:.3f}")
```

**Multi‑class Extension** – set `average='macro'` or `'weighted'`.

### ROC‑AUC & PR‑AUC <a name="roc-auc--pr-auc"></a>

**ROC Curve** plots **True Positive Rate (Recall)** vs **False Positive Rate (FPR)** across thresholds.  

**AUC (Area Under Curve)** quantifies separability; 0.5 = random, 1.0 = perfect.

**PR Curve** plots **Precision** vs **Recall**; **PR‑AUC** is more informative on imbalanced data.

**Formulas**  
- **TPR** = TP / (TP + FN)  
- **FPR** = FP / (FP + TN)

**Scikit‑learn Example**

```python
import numpy as np
from sklearn.metrics import roc_auc_score, roc_curve, precision_recall_curve, auc
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=42)
clf = RandomForestClassifier(random_state=0).fit(X_train, y_train)

# Predict probabilities for the positive class
y_proba = clf.predict_proba(X_test)[:, 1]

# ROC‑AUC
roc_auc = roc_auc_score(y_test, y_proba)

# ROC curve points
fpr, tpr, _ = roc_curve(y_test, y_proba)

# PR‑AUC
precision, recall, _ = precision_recall_curve(y_test, y_proba)
pr_auc = auc(recall, precision)

print(f"ROC‑AUC: {roc_auc:.3f}")
print(f"PR‑AUC:  {pr_auc:.3f}")
```

**Visualization** – Plot `fpr` vs `tpr` and `recall` vs `precision` (see Section 6).

### Log‑Loss (Cross‑Entropy) <a name="log-loss-cross-entropy"></a>

**Definition**  
\[
\text{LogLoss} = -\frac{1}{N}\sum_{i=1}^{N}\Big[ y_i \log(p_i) + (1-y_i)\log(1-p_i) \Big]
\]

where \(p_i\) is the predicted probability for the true class.

**Intuition**  
Penalizes confident but wrong predictions heavily. Ideal for probabilistic classifiers.

**When to Use / Avoid**  
*Use* when you need calibrated probabilities (e.g., risk scoring).  
*Avoid* if only class labels matter; accuracy/F1 are simpler.

**Scikit‑learn Example**

```python
from sklearn.metrics import log_loss

logloss = log_loss(y_test, y_proba)
print(f"Log‑Loss: {logloss:.4f}")
```

## Regression Metrics <a name="regression-metrics"></a>

### Mean Absolute Error (MAE) <a name="mean-absolute-error-mae"></a>

\[
\text{MAE} = \frac{1}{N}\sum_{i=1}^{N} |y_i - \hat{y}_i|
\]

**Intuition** – Average absolute deviation; same unit as the target, easy to interpret.

**When to Use** – When outliers should not dominate the error (e.g., house price prediction).

**Scikit‑learn Example**

```python
from sklearn.metrics import mean_absolute_error
y_true_reg = [3.0, 2.5, 4.1]
y_pred_reg = [2.8, 2.7, 3.9]

mae = mean_absolute_error(y_true_reg, y_pred_reg)
print(f"MAE: {mae:.3f}")
```

---

### Mean Squared Error (MSE) & RMSE <a name="mean-squared-error-mse--rmse"></a>

\[
\text{MSE} = \frac{1}{N}\sum_{i=1}^{N} (y_i - \hat{y}_i)^2
\]
\[
\text{RMSE} = \sqrt{\text{MSE}}
\]

**Intuition** – Squares large errors, thus penalizing outliers more heavily than MAE.

**When to Use** – When large deviations are especially undesirable (e.g., forecasting electricity demand).

**Scikit‑learn Example**

```python
from sklearn.metrics import mean_squared_error
import numpy as np

mse = mean_squared_error(y_true_reg, y_pred_reg)
rmse = np.sqrt(mse)

print(f"MSE:  {mse:.3f}")
print(f"RMSE: {rmse:.3f}")
```

---

### R² (Coefficient of Determination) <a name="r-coefficient-of-determination"></a>

\[
R^2 = 1 - \frac{\sum_{i}(y_i - \hat{y}_i)^2}{\sum_{i}(y_i - \bar{y})^2}
\]

**Intuition** – Proportion of variance explained by the model. R² = 1 → perfect fit; R² ≤ 0 indicates a model worse than predicting the mean.

**When to Use** – Quick sanity check for linear models; beware of over‑interpretation on non‑linear data.

**Scikit‑learn Example**

```python
from sklearn.metrics import r2_score

r2 = r2_score(y_true_reg, y_pred_reg)
print(f"R²: {r2:.3f}")
```

## Clustering Metrics <a name="clustering-metrics"></a>

Clustering is unsupervised, so metrics compare **internal structure** (cohesion vs separation) or **external ground truth** (if available).

### Silhouette Score <a name="silhouette-score"></a>

\[
s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}
\]

- \(a(i)\): average intra‑cluster distance for point *i*  
- \(b(i)\): lowest average distance of *i* to points in another cluster  

Overall score = mean of \(s(i)\) across all points, ranging from **‑1** (bad) to **1** (excellent).

**When to Use** – To select the optimal number of clusters (k) for algorithms like K‑Means.

**Scikit‑learn Example**

```python
from sklearn.metrics import silhouette_score
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=3, random_state=0).fit(X)
labels = kmeans.labels_

sil_score = silhouette_score(X, labels)
print(f"Silhouette Score: {sil_score:.3f}")
```

**Visualization** – Silhouette bar plot (see Section 6).

---

### Davies‑Bouldin Index (DBI) <a name="davies-bouldin-index-dbi"></a>

\[
\text{DBI} = \frac{1}{k}\sum_{i=1}^{k} \max_{j\neq i}\left(\frac{\sigma_i + \sigma_j}{d_{ij}}\right)
\]

- \(\sigma_i\): average distance of points in cluster *i* to its centroid  
- \(d_{ij}\): distance between centroids of clusters *i* and *j*

**Interpretation** – Lower DBI = better clustering (compact & well‑separated).

**Scikit‑learn Example**

```python
from sklearn.metrics import davies_bouldin_score

dbi = davies_bouldin_score(X, labels)
print(f"Davies‑Bouldin Index: {dbi:.3f}")
```
